This is a React single-page application powered by Vite.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:5173](http://localhost:5173) with your browser to see the result.

Run `npm install` to install dependencies, `npm run dev` to start Vite, and `npm run build` to create the production bundle. The FastAPI backend must allow the Vite origin (`http://localhost:5173`) for cookie-based API requests.
